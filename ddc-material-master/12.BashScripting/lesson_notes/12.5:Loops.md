# Loops

## Overview

Loops allow a set of commands to run repeatedly — either for a fixed sequence of items (`for` loop) or as long as a condition remains true (`while` loop). Without loops, you would need to repeat the same commands manually for each item or iteration.

**Use cases:**
- Add 10 users — same command, different username each time
- Run a command on 20 servers — same task, different target each time
- Monitor a condition — keep checking until something changes

---

## `for` Loop

A `for` loop runs for a **definitive sequence** — it iterates through a list and executes the commands once for each item.

### Syntax

```bash
for VARIABLE in list_of_items
do
    # commands — run once per item
done
```

- `for` opens the loop
- `done` closes it (like `fi` closes `if`)
- The variable takes the value of each item in turn
- Commands between `do` and `done` run on every iteration

---

### Script 13 — Basic `for` Loop (`13_forLoop.sh`)

```bash
#!/bin/bash

for VAR1 in java .net python ruby php
do
    echo "Looping........."
    sleep 1
    echo "##################################"
    echo "Value of VAR1 is $VAR1"
    echo "##################################"
    date
done
```

**How it works:**
- First iteration: `VAR1=java` → commands run → loop back
- Second iteration: `VAR1=.net` → commands run → loop back
- Continues through each item until the list is exhausted (5 iterations total)

**Live terminal output:**

```text
Looping.........
##################################
Value of VAR1 id java.
##################################
Sat Jun  6 12:10:39 AM UTC 2026
Looping.........
##################################
Value of VAR1 id .net.
##################################
Sat Jun  6 12:10:40 AM UTC 2026
...
```

`sleep 1` is included so the output does not scroll past too fast. Without it the loop runs in milliseconds.

### Script 14 — Adding Users with a `for` Loop (`14_forLoop.sh`)

This is a practical DevOps example — creating multiple user accounts with one loop instead of running `useradd` four times manually:

```bash
#!/bin/bash

MYUSERS="Alpha Beta Gamma Omega"

for usr in $MYUSERS
do
    echo "Adding a user called $usr."
    useradd "$usr"
    id "$usr"
    echo "###############################"
done
```

The variable `MYUSERS` holds a space-separated list. Each iteration assigns one name to `$usr`.

**Live terminal output:**

```text
Adding a user called Alpha.
uid=1001(Alpha) gid=1001(Alpha) groups=1001(Alpha)
###############################
Adding a user called Beta.
uid=1002(Beta) gid=1002(Beta) groups=1002(Beta)
###############################
Adding a user called Gamma.
uid=1003(Gamma) gid=1003(Gamma) groups=1003(Gamma)
###############################
Adding a user called Omega.
uid=1004(Omega) gid=1004(Omega) groups=1004(Omega)
###############################
```

> **Caution:** If you run the script a second time, `useradd` will fail with "user already exists". To make the script safe to run multiple times (idempotent), add a check:
>
> ```bash
> if id "$usr" &>/dev/null; then
>     echo "User $usr already exists."
> else
>     useradd "$usr"
> fi
> ```

### `for` Loop Variations

#### Brace Expansion — Numeric Sequences

```bash
for i in {1..5}
do
    echo "$i"
done
# Output: 1 2 3 4 5
```

With a step value `{start..end..step}`:

```bash
for i in {0..10..2}
do
    echo "Welcome $i times"
done
```

`{0..10..2}` expands to `0 2 4 6 8 10` before the loop runs. The three values mean `{start..end..step}`.

Output:

```text
Bash version 5.1.8(1)-release
Welcome 0 times
Welcome 2 times
Welcome 4 times
Welcome 6 times
Welcome 8 times
Welcome 10 times
```

> **Common mistake:** Missing the `do` keyword. Without it you get:
> `syntax error near unexpected token 'echo'`

#### C-Style `for` Loop — Arithmetic

```bash
for (( c=1; c<=5; c++ ))
do
    echo "Welcome $c times"
done
```

Format: `(( initialise ; condition ; increment ))`. This is a Bash-specific feature — must use `#!/bin/bash`, not `#!/bin/sh`.

Output:

```text
Welcome 1 times
Welcome 2 times
Welcome 3 times
Welcome 4 times
Welcome 5 times
```

#### Infinite `for` Loop

```bash
for (( ; ; ))
do
    echo "$RANDOM $RANDOM $RANDOM $RANDOM $RANDOM $RANDOM"
done
```

All three parts of `(( ; ; ))` are omitted — no condition ever becomes false, so the loop runs forever. Press `Ctrl+C` to stop it.

## `while` Loop

A `while` loop runs for as long as a **condition is true**. Unlike a `for` loop which has a fixed sequence, a `while` loop continues until the condition becomes false — or forever if it never does.

### Syntax

```bash
while [ condition ]
do
    # commands run while condition is true
done
```

---

### Script 15 — Finite `while` Loop (`15_whileLoop.sh`)

```bash
#!/bin/bash

counter=0

while [ $counter -lt 5 ]
do
    echo "Looping........."
    echo "Value of the counter is $counter."
    counter=$(( $counter + 1 ))
    sleep 1
done

echo "Out of the loop."
```

**How it works:**

| Iteration | `counter` value | Condition `counter -lt 5` | Result |
|-----------|----------------|--------------------------|--------|
| 1 | 0 | `0 < 5` = true | execute |
| 2 | 1 | `1 < 5` = true | execute |
| 3 | 2 | `2 < 5` = true | execute |
| 4 | 3 | `3 < 5` = true | execute |
| 5 | 4 | `4 < 5` = true | execute |
| — | 5 | `5 < 5` = false | **exit loop** |

**Live terminal output:**

```text
Looping.........
Value of the counter is 0.
Looping.........
Value of the counter is 1.
Looping.........
Value of the counter is 2.
Looping.........
Value of the counter is 3.
Looping.........
Value of the counter is 4.
Out of the loop.
```

### The Increment Line — Critical

```bash
counter=$(( $counter + 1 ))
```

This is what prevents an infinite loop. Without it, `counter` stays at `0` forever and `0 < 5` is always true. The loop never ends.

Alternative increment syntax:

```bash
counter=$((counter + 1))   # $ inside (()) is optional
((counter++))              # C-style increment — shortest form
```

---

### The Infinite `while` Loop — `while true`

```bash
while true
do
    # commands
done
```

`true` is a built-in Bash command that always returns exit code 0 (success). Since the condition is always satisfied, the loop never terminates on its own.

### Script 16 — Infinite `while` Loop with Doubling (`16_whileLoop.sh`)

```bash
#!/bin/bash

counter=2

while true
do
    echo "Looping........."
    echo "Value of the counter is $counter."
    counter=$(( counter * 2 ))
    sleep 1
done

echo "Out of the loop."
```

**Live terminal output:**

```text
Looping.........
Value of the counter is 2.
Looping.........
Value of the counter is 4.
Looping.........
Value of the counter is 8.
Looping.........
Value of the counter is 16.
Looping.........
Value of the counter is 32.
Looping.........
Value of the counter is 64.
Looping.........
Value of the counter is 128.
Looping.........
Value of the counter is 256.
^C
```

The `echo "Out of the loop."` line **never executes** because `while true` never becomes false. Pressing `Ctrl+C` is the only way to stop it.

> **Warning:** Be very careful with infinite loops in cron jobs. An infinite loop running as a scheduled background task will continuously consume CPU and memory until the system runs out of resources or the process is manually killed.

## Arithmetic in Bash — `$(( ))`

The `$(( ))` syntax performs integer arithmetic:

```bash
counter=$(( counter + 1 ))    # add 1
counter=$(( counter * 2 ))    # multiply by 2
counter=$(( counter - 1 ))    # subtract 1
counter=$(( counter / 2 ))    # divide by 2
counter=$(( counter % 3 ))    # modulo (remainder)
```

The `$` prefix inside `(( ))` is optional — both `$counter` and `counter` work inside the double parentheses.

## `for` vs `while` — When to Use Each

| Scenario | Use |
|----------|-----|
| Known list of items (users, servers, files) | `for` |
| Known number of iterations | `for` with brace expansion or C-style |
| Run until a condition changes | `while` |
| Run indefinitely (daemon-like behaviour) | `while true` |
| Counting up or down | Either — `while` with a counter or `for` with brace expansion |

## Summary

| Concept | Syntax |
|---------|--------|
| `for` loop | `for VAR in list; do ... done` |
| `for` with brace expansion | `for i in {1..5}; do ... done` |
| `for` with step | `for i in {0..10..2}; do ... done` |
| C-style `for` | `for ((c=1; c<=5; c++)); do ... done` |
| Infinite `for` | `for (( ; ; )); do ... done` |
| `while` loop | `while [ condition ]; do ... done` |
| Infinite `while` | `while true; do ... done` |
| Increment counter | `counter=$((counter + 1))` or `((counter++))` |
| Open keyword | `for` or `while` |
| Close keyword | `done` |
| Stop infinite loop | `Ctrl+C` |
