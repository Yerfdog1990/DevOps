# Linux Archiving

## 1. What is Archiving?

**Archiving** is the process of bundling files and directories into a single file, often with compression. Common use cases:

- **Backup** — archive logs or data before clearing disk space
- **Restore** — extract a backup archive to recover files
- **Transfer** — package files for sending over a network or internet
- **Software distribution** — many Linux packages and source code come as archives

There are two main tools for archiving in Linux: `tar` and `zip`.

---

## 2. Method 1 — `tar` (Tape Archive)

`tar` is the traditional and most widely used archiving tool in Linux. It is feature-rich and supports multiple compression formats.

### Creating a Tarball

```bash
tar -czvf archive_name.tar.gz /path/to/directory
```

### Options Breakdown

| Option | Meaning |
|---|---|
| `-c` | **Create** a new archive |
| `-z` | **Compress** using gzip (gunzip) |
| `-v` | **Verbose** — print files being archived |
| `-f` | **File** — the next argument is the archive filename |
| `-x` | **Extract** from an archive |
| `-C` | **Change directory** — extract to a specific location |

> The order matters: the **archive name comes first**, then the **source path**.

### File Extensions

| Extension | Meaning |
|---|---|
| `.tar` | Archive only, no compression |
| `.tar.gz` or `.tgz` | Archive + gzip compression |
| `.tar.bz2` | Archive + bzip2 compression |
| `.tar.xz` | Archive + xz compression |

---

### Practical Example — Archive Jenkins Logs

Navigate to the log directory:
```bash
cd /var/log
ls
# You should see a jenkins/ directory
```

Create a compressed archive with a timestamp in the name:
```bash
tar -czvf jenkins_06122020.tar.gz jenkins/
```

Verify the archive was created:
```bash
ls -ltr
# You should see jenkins_06122020.tar.gz at the bottom (most recent)
```

Check the file type (useful even without an extension):
```bash
file jenkins_06122020.tar.gz
# Output: gzip compressed data   ← confirms it's a compressed archive
```

---

### Extracting a Tarball

#### Extract in the current directory
```bash
tar -xzvf jenkins_06122020.tar.gz
```

#### Extract to a specific directory using `-C`
```bash
tar -xzvf jenkins_06122020.tar.gz -C /opt/
```

The `-C` (capital C) option tells tar where to extract the contents. After this, you should see the `jenkins/` directory inside `/opt/`.

---

### Other Compression Options

| Option | Compression Type | Extension |
|---|---|---|
| `-z` | gzip (default, most common) | `.tar.gz` |
| `-j` | bzip2 (better compression, slower) | `.tar.bz2` |
| `-J` | xz (best compression, slowest) | `.tar.xz` |
| `-a` | Auto-detect based on file extension | any |

```bash
tar -cjvf archive.tar.bz2 /path/to/dir    # bzip2 compression
tar -cJvf archive.tar.xz /path/to/dir     # xz compression
tar -cavf archive.tar.gz /path/to/dir     # auto-detect compression
```

---

### Other Useful `tar` Options

| Command | What it does |
|---|---|
| `tar -czvf name.tar.gz dir/` | Create a compressed archive |
| `tar -xzvf name.tar.gz` | Extract in current directory |
| `tar -xzvf name.tar.gz -C /path/` | Extract to a specific directory |
| `tar -tzvf name.tar.gz` | **List** contents without extracting |
| `tar -d` | **Compare** (diff) two tarballs |
| `tar --update` | **Update** an existing tarball with newer files |

```bash
tar -tzvf jenkins_06122020.tar.gz      # Preview contents before extracting
```

## 3. Method 2 — `zip` / `unzip`

`zip` is a simpler and more universally recognized archiving format, especially for cross-platform use (Windows, macOS, Linux all support `.zip`).

### Install zip and unzip

`zip` and `unzip` are not installed by default on CentOS — install both together:

```bash
yum install zip unzip -y
```

---

### Creating a Zip Archive

```bash
zip -r archive_name.zip /path/to/directory
```

| Option | Meaning |
|---|---|
| `-r` | **Recursive** — required when archiving a directory |

> Without `-r`, `zip` will only archive the directory entry, not its contents.

### Practical Example

```bash
cd /var/log
zip -r jenkins_06122020.zip jenkins/
```

Move the archive to another location:
```bash
mv jenkins_06122020.zip /opt/
cd /opt/
```

---

### Extracting a Zip Archive

```bash
unzip jenkins_06122020.zip
```

If a directory with the same name already exists, `unzip` will prompt you before overwriting. Remove the existing directory first if needed:

```bash
rm -rf jenkins/              # Remove existing directory
unzip jenkins_06122020.zip   # Then extract cleanly
```

---

## 4. tar vs zip — When to Use Which

| Feature | `tar` | `zip` |
|---|---|---|
| Native to Linux | ✅ Yes | ❌ Needs install |
| Cross-platform (Windows/Mac) | Limited | ✅ Universal |
| Multiple compression formats | ✅ gzip, bzip2, xz | gzip only |
| Preserves Linux permissions | ✅ Yes | Partial |
| Most common for Linux software | ✅ Yes | Less common |
| Simpler to use | Moderate | ✅ Simpler |

> Use `tar` for Linux-to-Linux transfers, server backups, and software packages. Use `zip` when sharing with Windows/Mac users or when simplicity is preferred.

---

## 5. Naming Archives — Best Practice

Always include a **timestamp** in the archive name so you can identify when the backup was taken:

```bash
# Good naming convention:
tar -czvf jenkins_06122020.tar.gz jenkins/       # date: 06-12-2020
zip -r httpd_backup_06122020.zip /etc/httpd/     # service + date
```

A clear name prevents confusion when you have multiple backups.

| Command | What it does |
|---|---|

| `tar -xzvf name.tar.gz` | Extract tar archive in current directory |
| `tar -xzvf name.tar.gz -C /path/` | Extract to a specific directory |
| `tar -tzvf name.tar.gz` | List contents of a tar archive |
| `tar -cjvf name.tar.bz2 dir/` | Create archive with bzip2 compression |

---

## 7. Key Takeaways

- Archiving bundles files into one, compression reduces the size — `tar -z` does both at once.
- `tar` option order: **`-czvf`** to create, **`-xzvf`** to extract. The **archive name always comes first**, the source/destination path second.
- Always include a **timestamp** in backup archive names for easy identification.
- Use `-C` (capital) with `tar -x` to extract into a specific directory.
- `tar -tzvf` lists archive contents without extracting — always preview before extracting to an important location.
- `zip` is simpler and more cross-platform; `tar` is more powerful and native to Linux.
- `zip` requires `-r` to archive directories recursively — without it, the contents are skipped.
- Use the `file` command to identify what kind of archive a file is, even without an extension.
- Common real-world workflow: archive logs → move archive to backup storage → delete original logs → free up disk space.
