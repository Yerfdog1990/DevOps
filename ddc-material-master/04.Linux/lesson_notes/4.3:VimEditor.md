# Vim Editor

## 1. What is Vim?

Vim is a text editor used in the Linux terminal. Throughout Linux and DevOps work, you'll regularly create and edit text files, so getting comfortable with a terminal editor is essential.

- `vi` comes pre-installed on CentOS by default.
- `vim` is an enhanced version of `vi` with more features.
- If you already know another terminal editor like **Nano**, you can use that instead.

**Install vim on CentOS:**
```bash
sudo yum install vim -y
```

> If installation fails (e.g. no internet on the VM), use an Ubuntu VM instead — vim is pre-installed there. Don't waste time troubleshooting; networking with Vagrant is covered later.

---

## 2. Opening and Creating Files

```bash
vim firstfile.txt       # Open existing file, or create new one if it doesn't exist
vim /path/to/file       # Open a file using absolute path
```

> File extensions are optional in Linux — `vim firstfile` works just as well.

---

## 3. The Three Modes of Vim

Vim operates in three distinct modes. Understanding these is the key to using Vim.

```
┌─────────────────────────────────────────────────────┐
│                   COMMAND MODE                      │
│            (default when file opens)                │
│                                                     │
│   Press i or o ──────────────► INSERT MODE          │
│   Press : ───────────────────► EXTENDED MODE        │
│                                                     │
│   From Insert or Extended: press Esc ──► COMMAND    │
└─────────────────────────────────────────────────────┘
```

| Mode | How to Enter | What You Can Do |
|---|---|---|
| **Command mode** | Default on open / press `Esc` | Navigate, copy, cut, paste, undo, search |
| **Insert mode** | Press `i` or `o` from command mode | Type and edit text |
| **Extended mode** | Press `:` from command mode | Save, quit, set options |

> You must always return to **command mode** (press `Esc`) before switching to extended mode.

---

## 4. Insert Mode

| Key | Action |
|---|---|
| `i` | Enter insert mode at the current cursor position |
| `o` | Enter insert mode on a **new line below** the current line |

Once in insert mode, type normally. Press `Esc` when done to return to command mode.

---

## 5. Extended Mode — Saving and Quitting

Press `Esc` first, then `:` to enter extended mode.

| Command | Action |
|---|---|
| `:w` | **Write** (save) the file |
| `:q` | **Quit** (only works if no unsaved changes) |
| `:wq` | **Save and quit** at the same time |
| `:q!` | **Force quit without saving** — discards all changes |

**Typical workflow:**
```
Make changes in insert mode
→ Esc (back to command mode)
→ :wq (save and quit)
```

**Made a mistake and don't want to save?**
```
Esc → :q!
```

## 6. Navigating in Command Mode

### Line Navigation
| Key | Action |
|---|---|
| `gg` | Jump to the **first line** of the file |
| `G` (Shift+G) | Jump to the **last line** of the file |
| Arrow keys | Move cursor up/down/left/right |

### Word Navigation
| Key | Action |
|---|---|
| `w` | Move cursor **one word forward** |
| `5w` | Move cursor **5 words forward** (n = any number) |
| `b` | Move cursor **one word backward** |

### Show Line Numbers
```
:se nu
```
Enables line numbers on the left — very useful for navigating large files.

---

## 7. Copy, Cut, and Paste

### Copy (Yank)
| Command | Action |
|---|---|
| `yy` | Copy (yank) the **current line** |
| `4yy` | Copy **4 lines** starting from the cursor |
| `nyy` | Copy **n lines** (replace n with any number) |

### Paste
| Command | Action |
|---|---|
| `p` | Paste **below** the current line |
| `P` (Shift+P) | Paste **above** the current line |

### Cut (Delete and Paste)
| Command | Action |
|---|---|
| `dd` | Cut (delete) the **current line** |
| `5dd` | Cut **5 lines** starting from the cursor |
| `ndd` | Cut **n lines** |

> `dd` doesn't just delete — it **cuts** the line into a buffer. You can paste it with `p`.

**Copy-paste workflow:**
```
Take cursor to target line → yy → move cursor to destination → p
```

**Cut-paste workflow:**
```
Take cursor to target line → dd → move cursor to destination → p
```

---

## 8. Undo

| Key | Action |
|---|---|
| `u` | Undo the last change |

Press `u` repeatedly to undo multiple changes. Very useful when you accidentally delete lines with `dd` or `ndd`.

---

## 9. Searching in a File

You must be in **command mode** to search.

```
/searchterm
```

**Example — search for the word "network":**
```
/network
```

Then press `Enter`. Vim highlights all matches and jumps to the first one.

| Key | Action |
|---|---|
| `/word` | Search forward for "word" |
| `n` | Jump to the **next** match |
| `N` (Shift+N) | Jump to the **previous** match |

> **Vim search is case-sensitive.** Searching `/network` will NOT match `Network` or `NETWORK`.

## 10. Vim Shortcuts — Quick Reference

### Navigation
| Shortcut | Action |
|---|---|
| `gg` | Go to first line |
| `G` | Go to last line |
| `w` / `nw` | Move forward one/n words |
| `b` | Move backward one word |

### Editing
| Shortcut | Action |
|---|---|
| `i` | Insert at cursor |
| `o` | Insert on new line below |
| `u` | Undo |
| `dd` / `ndd` | Cut current / n lines |
| `yy` / `nyy` | Copy current / n lines |
| `p` / `P` | Paste below / above |

### Extended Mode Commands
| Command | Action |
|---|---|
| `:se nu` | Show line numbers |
| `:w` | Save |
| `:q` | Quit |
| `:wq` | Save and quit |
| `:q!` | Force quit without saving |

### Search
| Command | Action |
|---|---|
| `/word` | Search for "word" |
| `n` | Next match |
| `N` | Previous match |

---

## 11. Key Takeaways

- Vim has **three modes**: command, insert, and extended. Always know which mode you're in.
- Press `Esc` to return to command mode at any time.
- `i` to start typing, `Esc` to stop, `:wq` to save and quit — this is the core loop.
- `:q!` is your escape hatch when you've made changes you don't want to keep.
- `dd` cuts, `yy` copies, `p` pastes — these work like cut/copy/paste in any editor.
- Search with `/term`, navigate matches with `n`.
- Linux (and Vim) is **case-sensitive** everywhere — in commands, filenames, and searches.
- You don't need to memorize everything at once — the more you practice, the more natural it becomes.
