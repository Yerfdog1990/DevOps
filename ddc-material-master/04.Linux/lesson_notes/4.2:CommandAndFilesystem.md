# Linux Commands and Filesystem

## 1. Basic Commands

### `whoami`
Displays the currently logged-in user.
```bash
whoami
# Output: vagrant
```

### `pwd` — Print Working Directory
Shows the full path of the directory you are currently in.
```bash
pwd
# Output: /home/vagrant
```

### `ls` — List
Lists files and directories in the current location.
```bash
ls
# Output: (empty if no files)
```

### `cat` — Concatenate / Read File
Reads and displays the contents of a file.
```bash
cat /etc/os-release
# Shows OS name and version
```

---

## 2. Understanding the Shell Prompt

The shell prompt gives you key information at a glance:

```
vagrant@localhost:~$
```

| Part | Meaning |
|---|---|
| `vagrant` | Current username |
| `@localhost` | Hostname (defaults to `localhost` if not set) |
| `~` | Tilde = home directory of the current user |
| `$` | Normal (non-root) user shell |

When switched to root, the prompt changes:

```
root@localhost:~#
```

| Part | Meaning |
|---|---|
| `root` | Root username |
| `~` | Home directory of root (`/root`) |
| `#` | Root user shell (elevated privileges) |

---

## 3. Switching to Root User

```bash
sudo -i
```

- Switches from the `vagrant` user to the `root` user.
- Only the `vagrant` user has permission to run `sudo -i`.
- After switching, `whoami` returns `root` and `pwd` returns `/root`.

## 4. Navigating the Filesystem

### `cd` — Change Directory

```bash
cd /          # Go to the root directory
cd /bin       # Absolute path navigation
cd            # Return to current user's home directory (shortcut when lost)
```

> **Tip:** When you're lost in the filesystem, just type `cd` and press Enter to return to your home directory.

---

## 5. Root Directory vs. Root User's Home Directory

This is a common source of confusion:

| Term | Path | What it is |
|---|---|---|
| Root directory | `/` | The top-level directory of the entire Linux filesystem |
| Root user's home | `/root` | The home folder belonging to the `root` user |

```bash
cd /     # Takes you to the ROOT DIRECTORY (top of filesystem)
cd       # Takes you to ROOT USER's HOME (/root) — only if you are root
```

---

## 6. Linux Directory Structure

The Linux filesystem follows a standard layout. The root directory `/` is the top-level container for everything.

```
/
├── bin       User executables (commands like mv, scp, whoami, pwd)
├── sbin      System executables (root-only commands like mkfs.ext4, reboot)
├── etc       Configuration files (hostname, yum, network settings)
├── home      Home directories for normal users (/home/username)
├── root      Home directory for the root user
├── boot      Bootloader and kernel files (grub2, vmlinuz, initramfs)
├── tmp       Temporary files (cleared regularly — do NOT store important data here)
├── var       Variable/server data (logs, web server files)
├── srv       Server data (alternative to /var)
├── proc      Dynamic system information (read by commands like uptime, free)
├── sys       System hardware information (dynamic)
├── mnt       Mount points for filesystems
├── media     Mount points for removable media
└── opt       Optional/third-party software
```

## 7. Key Directories in Detail

### `/bin` — User Executables
Contains commands that normal users can run.
```bash
cd /bin
ls
# You'll see: mv, scp, yum, whoami, pwd, and many more
```

### `/sbin` — System Executables
Contains commands primarily for the root user (system administration).
```bash
cd /sbin
# Examples: mkfs.ext4 (format partition), reboot
# Normal users can run some with sudo
```

### `/etc` — Configuration Files
Central location for all system configuration.
```bash
cat /etc/hostname       # View/change the system hostname
# Also contains: yum config, network config, and much more
```

### `/tmp` — Temporary Files
Used by the OS and tools for temporary data storage.
- Data here is **not permanent**.
- Automation tools and scripts often use `/tmp` for intermediate files.
- **Do not store anything here that you need later.**

### `/boot` — Bootloader and Kernel
```bash
cd /boot
ls
# vmlinuz      → Linux kernel
# initramfs    → Initial RAM filesystem
# grub2/       → Bootloader configuration (kernel version, boot parameters)
```

### `/proc` — System Information (Dynamic)
Contains virtual files that reflect real-time system state.
```bash
uptime             # Reads from /proc/uptime — shows how long system has been running
free -m            # Reads RAM info — contents change dynamically
```
> Files in `/proc` are not regular files — they are generated dynamically by the kernel.

### `/home` — Normal User Home Directories
Each user gets their own directory here.
```
/home/vagrant    → Home dir for user 'vagrant'
/home/alice      → Home dir for user 'alice'
```

### `/root` — Root User's Home Directory
The home directory for the root (superuser) account. Not inside `/home`.

## 8. Absolute vs. Relative Paths

| Type | Description | Example |
|---|---|---|
| Absolute path | Starts from root `/`, works from anywhere | `/bin/whoami` |
| Relative path | Starts from current directory | `cd bin` (only works if you're in `/`) |

```bash
# Absolute (always works regardless of where you are):
cd /bin

# Relative (only works if already in /):
cd bin
```

## 9. File and Directory Management Commands

### `exit` — Log Out / Switch Back
```bash
exit    # If root → goes back to vagrant user
exit    # If vagrant → logs out entirely from SSH session
```

---

### `mkdir` — Make Directory
Creates one or more directories.
```bash
mkdir dev                   # Create a single directory
mkdir ops backup            # Create multiple directories at once
mkdir textdir               # Create a directory to hold text files
```

---

### `touch` — Create Empty File / Update Timestamp
Creates an empty file, or updates the timestamp of an existing file.
```bash
touch testfile.txt                    # Create a single empty file
touch devopsfile{1..10}.txt           # Create 10 files: devopsfile1.txt to devopsfile10.txt
```

> The `{1..10}` brace expansion is like a range — it generates a sequence of numbers automatically.

---

### `cp` — Copy Files and Directories
```bash
# Copy a file (relative path)
cp devopsfile1.txt dev/

# Copy a file (absolute path — recommended while learning)
cp /home/vagrant/devopsfile2.txt /home/vagrant/dev/

# Copy a directory — requires the -r (recursive) option
cp -r dev backup/
```

> You **cannot** copy a directory without `-r`. You'll get an error: `omitting directory`.

**Listing copied results:**
```bash
ls dev/                          # Relative path
ls /home/vagrant/dev             # Absolute path — same result
```

---

### `mv` — Move or Rename Files and Directories
```bash
# Move a file to a directory
mv devopsfile3.txt ops/

# Move a directory into another directory (no -r needed)
mv ops/ dev/

# Rename a file (mv used as rename)
mv testfile1.txt testfile22.txt

# Move all .txt files to a directory using wildcard
mv *.txt textdir/
```

> `mv` doubles as a rename command — just give a new name as the destination.

---

### `rm` — Remove Files and Directories

```bash
# Remove a single file
rm devopsfile10.txt

# Remove a directory — requires -r (recursive)
rm -r mobile/

# Remove everything in the current directory (DANGEROUS)
rm -rf *
```

> ⚠️ **Warning:** There is no recycle bin or undo in Linux. Deleted files are gone permanently. If you accidentally delete critical files (e.g., in `/etc`), recovery requires disk restoration, which is complex and not guaranteed.
>
> Always double-check:
> 1. What directory you are in (`pwd`)
> 2. What you are deleting before running `rm -rf *`

---

### `history` — View Command History
Shows all previously executed commands in the current session.
```bash
history
```

## 10. Linux Command Syntax

Every Linux command follows this general pattern:

```
command  [options]  [arguments]
```

| Part | Description | Example |
|---|---|---|
| Command | The program to run | `cp` |
| Options | Flags that modify behavior | `-r`, `--recursive` |
| Arguments | Inputs the command acts on | `source/` `destination/` |

**Option format rules:**
- Single letter options use a single hyphen: `-r`, `-f`, `-i`
- Word options use double hyphen: `--recursive`, `--help`, `--force`
- Both can often be used interchangeably: `-r` = `-R` = `--recursive` (for `cp`)

**Examples:**
```bash
ls                          # Command only
ls -l                       # Command + option (long listing format)
ls /tmp                     # Command + argument (list a specific path)
cp -r dev/ backup/          # Command + option + two arguments
```

---

## 11. Getting Help — `--help`

You don't need to memorize every option. Use `--help` to see all available options for any command.

```bash
cp --help
```

This shows:
- Usage syntax
- All available options with descriptions

**Common `cp` options shown by `--help`:**

| Option | Meaning |
|---|---|
| `-a` | Archive (preserves metadata) |
| `-f` | Force (overwrite without prompting) |
| `-i` | Interactive (asks before overwriting) |
| `-r` / `-R` / `--recursive` | Copy directories recursively |

> You can also Google any command for more examples and explanations — that's completely fine.

---

## 12. Wildcards

The `*` (asterisk) is a wildcard meaning **everything** or **match anything**.

```bash
*.txt           # All files ending in .txt
devopsfile*     # All files starting with "devopsfile"
*               # Everything in the current directory
```

**Example — move all `.txt` files to a folder:**
```bash
mv *.txt textdir/
```

**Example — delete everything in current directory (use with extreme caution):**
```bash
rm -rf *
```

---

## 14. Key Takeaways

- The **tilde `~`** in the prompt always represents the current user's home directory. `cd ~` and `cd` do the same thing.
- **`$`** = normal user shell; **`#`** = root user shell.
- The **root directory `/`** and the **root user's home `/root`** are different things.
- `cd` with no arguments always brings you back to your home directory — useful when lost.
- `/etc` is for configuration, `/bin` for user commands, `/sbin` for system commands, `/tmp` for temporary files.
- Files in `/proc` and `/sys` are dynamic — they reflect live system information.
- Use **absolute paths** while you're learning — they work from anywhere and build familiarity with the filesystem.
- You **must** use `-r` to copy or remove directories.
- `mv` serves double duty: moving files **and** renaming them.
- `rm` is permanent — no trash, no undo. Always verify your location with `pwd` before deleting.
- Use `--help` on any command to see its options — you don't need to memorize them.
