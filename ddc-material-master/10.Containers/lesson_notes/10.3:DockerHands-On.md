# Docker Hands-On

## 1. Setup: Vagrantfile

Create a directory and place the Vagrantfile inside it. This Vagrantfile is based on **Ubuntu 20 (focal64)** and automatically installs Docker Engine via a provisioning script.

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/focal64"

  config.vm.network "private_network", ip: "192.168.56.82"
  config.vm.network "public_network"

  config.vm.provider "virtualbox" do |vb|
    vb.memory = "2048"
  end

  config.vm.provision "shell", inline: <<-SHELL
    sudo apt-get update
    sudo apt-get install ca-certificates curl gnupg -y

    sudo install -m 0755 -d /etc/apt/keyrings
    curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
    sudo chmod a+r /etc/apt/keyrings/docker.gpg

    echo \
      "deb [arch="$(dpkg --print-architecture)" signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
      "$(. /etc/os-release && echo "$VERSION_CODENAME")" stable" | \
      sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

    sudo apt-get update
    sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin -y
  SHELL
end
```

Bring up the VM:

```bash
vagrant up
vagrant ssh
sudo -i        # become root
```

## 2. Installing Docker Engine (Manual Steps)

If installing Docker manually on Ubuntu, the steps are:

### Step 1 — Install prerequisites

```bash
sudo apt-get update
sudo apt-get install \
    ca-certificates \
    curl \
    gnupg \
    lsb-release -y
```

### Step 2 — Add Docker's official GPG key

```bash
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
```

### Step 3 — Add the Docker repository

```bash
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

### Step 4 — Install Docker Engine

```bash
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-compose-plugin -y
```

## 5. Running Your First Container

```bash
docker run hello-world
```

What happens:
- Docker looks for the `hello-world` image **locally** — not found
- Docker **pulls** it from Docker Hub automatically
- The container runs, prints a test message, and **exits**

```bash
docker ps -a
# Shows the exited hello-world container with a random name (e.g. relaxed_sammet)
```

> This container's only job is to print a message and stop — its status will be `Exited`.

## 6. Running an Nginx Container

```bash
docker run --name web01 -d -p 9080:80 nginx
```

| Flag | Meaning |
|---|---|
| `--name web01` | Name the container `web01` |
| `-d` | Run in the **background** (detached mode) |
| `-p 9080:80` | Map **host port 9080** → **container port 80** |

```bash
docker ps    # Confirm web01 is running
```

### Port Mapping Explained

Containers run in an **internal network** — they are not directly accessible from outside. Port mapping bridges the gap:

```
Browser → VM IP:9080 → Docker → Container web01:80
```

### Accessing the Container

**From inside the VM (internal IP):**

```bash
docker inspect web01     # Find the container's internal IP (e.g. 172.17.0.2)
curl http://172.17.0.2:80
```

**From the browser (host port):**

```bash
ip addr show             # Find the VM's IP address (e.g. 192.168.56.82)
```

Open browser → `http://192.168.56.82:9080` → Nginx default page

## 7. Building Your Own Image

### Step 1 — Create a directory and Dockerfile

```bash
mkdir images
cd images/
vim Dockerfile
```

### Step 2 — The Dockerfile

```dockerfile
# Stage 1: Build image — download and prepare the website
FROM ubuntu:latest AS BUILD_IMAGE
RUN apt update && apt install wget unzip -y
RUN wget https://www.tooplate.com/zip-templates/2128_tween_agency.zip
RUN unzip 2128_tween_agency.zip && \
    cd 2128_tween_agency && \
    tar -czf tween.tgz * && \
    mv tween.tgz /root/tween.tgz

# Stage 2: Final image — run the web server
FROM ubuntu:latest
LABEL "project"="Marketing"
ENV DEBIAN_FRONTEND=noninteractive

RUN apt update && apt install apache2 git wget -y
COPY --from=BUILD_IMAGE /root/tween.tgz /var/www/html/
RUN cd /var/www/html/ && tar xzf tween.tgz

CMD ["/usr/sbin/apache2ctl", "-D", "FOREGROUND"]
VOLUME /var/log/apache2
WORKDIR /var/www/html/
EXPOSE 80
```

**Key Dockerfile instructions explained:**

| Instruction | Purpose |
|---|---|
| `FROM` | Sets the **base image** (official Ubuntu from Docker Hub) |
| `RUN` | Executes a shell command during image build |
| `COPY --from` | Copies files from a previous build stage (multi-stage build) |
| `CMD` | Default command to run when the container starts |
| `EXPOSE` | Documents which port the container listens on |
| `VOLUME` | Mounts a directory for persistent storage |
| `WORKDIR` | Sets the working directory inside the container |
| `ENV` | Sets environment variables |
| `LABEL` | Adds metadata to the image |

### Step 3 — Build the image

```bash
docker build -t tesimg .
```

| Part | Meaning |
|---|---|
| `-t tesimg` | Tag/name the image `tesimg` |
| `.` | Look for the Dockerfile in the **current directory** |

```bash
docker images    # Confirm the new image appears
```

### Step 4 — Run a container from your image

```bash
docker run -P -d tesimg
```

| Flag | Meaning |
|---|---|
| `-P` (capital) | Automatically assign a random **host port** |
| `-d` | Run in the background |

```bash
docker ps    # Check the auto-assigned host port (e.g. 49154)
ip addr show # Get the VM's IP
```

Open browser → `http://<VM-IP>:49154` → Your custom website is live inside a container!

## 8. Cleanup

When done, remove all containers and images for a clean state:

```bash
# Stop running containers
docker stop web01 heuristic_hugle

# Remove all containers
docker ps -a
docker rm heuristic_hugle web01 competent_gates elastic_ramanujan relaxed_sammet

# Remove all images
docker images
docker rmi a54ee9c44b3b 6130c26b5558 057d51c0049c 825d55fb6340 12766a6745ee feb5d9fea6a5

# Verify everything is clean
docker ps -a
docker images
```

## 9. Summary of Commands

```bash
# Check Docker service
systemctl status docker

# Images
docker images              # list local images
docker build -t <name> .   # build image from Dockerfile
docker rmi <image-id>      # remove an image

# Containers
docker run hello-world                        # run a test container
docker run --name web01 -d -p 9080:80 nginx   # run nginx with port mapping
docker run -P -d tesimg                       # run custom image, auto port
docker ps                                     # running containers
docker ps -a                                  # all containers
docker inspect <name>                         # inspect container details
docker stop <name>                            # stop a running container
docker rm <name>                              # remove a stopped container
```
